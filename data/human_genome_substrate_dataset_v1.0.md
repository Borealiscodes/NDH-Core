# Human Genome Substrate Dataset v1.0
## NDH‑CORE / Biological Substrate Reference

This document provides a high‑level, safe, non‑dual summary of the human genome
for use as a substrate within NDH‑CORE, NDH‑PLATFORMS routing, and EXPRESSIVE
anchoring. No raw sequencing data is included. All values represent widely
accepted public scientific consensus as of 2026.

### Chromosome‑level summary (nuclear genome, haploid)

- **Chromosomes:** 1–22 (autosomes), X, Y  
- **Size range:**  
  - Largest: chr1 ≈ 260 Mbp  
  - Smallest: chr21 ≈ 50 Mbp   [Oxford Reference](https://www.oxfordreference.com/display/10.1093/oi/authority.20110803095949809)  
- **Gene distribution:**  
  - Gene‑rich: chr19 (~23 genes/Mbp)  
  - Gene‑poor: chr13, Y (~5 genes/Mbp)   [Oxford Reference](https://www.oxfordreference.com/display/10.1093/oi/authority.20110803095949809)  

---

### Functional composition

- **Protein‑coding genes:** ~19k–20k, 1–2% of total DNA   [grokipedia.com](https://grokipedia.com/page/Human_genome)  [Oxford Reference](https://www.oxfordreference.com/display/10.1093/oi/authority.20110803095949809)  
- **Other RNAs:** ≥750 genes (e.g., ~500 tRNA genes)   [Oxford Reference](https://www.oxfordreference.com/display/10.1093/oi/authority.20110803095949809)  
- **Regulatory DNA:** promoters, enhancers, silencers, insulators, origins of replication   [Wikipedia](https://en.wikipedia.org/wiki/Human_genome)  
- **Repetitive / transposable elements:** ~45% of genome derived from transposons; >50% repetitive overall   [Oxford Reference](https://www.oxfordreference.com/display/10.1093/oi/authority.20110803095949809)  [Wikipedia](https://en.wikipedia.org/wiki/Human_genome)  

---

### Variation and reference

- **Reference assembly:** GRCh38.p14 (current standard), ~3.1 Gbp haploid   [Wikipedia](https://en.wikipedia.org/wiki/Human_genome)  
- **Pangenome:** 2023 draft pangenome built from 47 diverse genomes   [Wikipedia](https://en.wikipedia.org/wiki/Human_genome)  
- **Individual variation:**  
  - Any two humans: ~99.9% identical  
  - Differences: ~3–5 million variants (SNPs + indels + CNVs)   [grokipedia.com](https://grokipedia.com/page/Human_genome)

## Provenance & Safety

This dataset is derived from publicly available, non‑sensitive, non‑identifiable
human genome reference information (GRCh38/p14 and 2023 Human Pangenome draft).
No individual‑specific genomic data is included. All content is aggregated,
high‑level, and compliant with NDH‑CORE safety constraints.

This file is intended solely as a conceptual substrate for NDH architectural
modeling, expressive anchoring, and cross‑manifold experimentation. It must not
be used for medical, clinical, or bioinformatic analysis pipelines.

NDH‑CORE Invariant: All biological substrates included in NDH‑CORE/data must
remain non‑dual, non‑identifiable, and informationally safe.
