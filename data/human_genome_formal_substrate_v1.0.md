## NDH‑CORE / Formal Biological Substrate

## 1. Genome Overview

- Genome Type: Nuclear + Mitochondrial
- Haploid Size: ~3.1–3.2 billion base pairs
- Diploid Size: ~6.2 billion base pairs
- Chromosomes: 22 autosomes + X + Y
- Mitochondrial Genome: 16,569 bp, circular, 37 genes

---

## 2. Chromosome Composition (Haploid)

- Largest: Chromosome 1 (~260 Mbp)
- Smallest: Chromosome 21 (~50 Mbp)
- Gene‑rich: Chromosome 19 (~23 genes/Mbp)
- Gene‑poor: Chromosome 13, Y (~5 genes/Mbp)

## 3. Functional Categories

- Protein‑coding genes: ~19,000–20,000
- Non‑coding RNAs: ≥750 (including ~500 tRNA genes)
- Regulatory DNA: promoters, enhancers, silencers, insulators
- Repetitive Elements: >50% of genome
- Transposon‑derived content: ~45%

## 4. Variation Summary

- Human–human similarity: ~99.9%
- Typical variation: ~3–5 million SNPs + indels + CNVs
- Reference assembly: GRCh38.p14
- Pangenome: 2023 draft (47 genomes)
