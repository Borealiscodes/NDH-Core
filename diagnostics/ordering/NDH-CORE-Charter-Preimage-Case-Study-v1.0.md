# 🌑 **Case Study — The Pre‑Existing Charter Paradox**  
### *How a charter governs before it is written*

A governance charter (like **NDH‑CORE Charter v1.2**) can influence system behavior *before* it is authored when:

- the system already contains **constitutional constraints**,  
- those constraints imply the **shape** of the future charter,  
- and diagnostics must obey those constraints even without the charter being written.

This is called a **constitutional pre‑image**.

It is not mystical.  
It is not curvature.  
It is not emergent geometry.  
It is simply **logic that precedes documentation**.
